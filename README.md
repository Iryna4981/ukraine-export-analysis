
# Аналіз географії експорту України (2015-2024)

## Опис проєкту
Аналітичний проєкт, присвячений дослідженню географічної структури експорту товарів України у 2015-2024 роках.

Досліджено вартісні показники експорту в доларах США та країни призначення, без урахування країн, через які здійснювалася торгівля.


## Мета дорслідження
- Проаналізувати динаміку вартості експорту України у 2015-2024 роках.
- Визначити основних торговельних партнерів за сумарною вартістю експорту.
- Порівняти географічну структуру експорту у довоєнний період (2015-2021) та період після початку повномасштабної війни (2022-2024).

## Висновки
У ході дослідження виявлено помітні зміни у географічній структурі експорту України після початку повномасштабної війни. Зокрема, змінився склад основних торговельних партнерів та зросла роль окремих європейських ринків. У 2024 році спостерігалося часткове відновлення загальної вартості експорту.
